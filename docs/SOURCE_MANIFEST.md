# Source Manifest and Lawful Provenance

- Data origin: entirely synthetic records generated by this repository.
- External datasets used: none.
- Public source data copied: none.
- Personal/confidential data: none; emails use the reserved `.test` domain and names are synthetic examples.
- Generator seed: `20261022` by default.
- Generation rules: see `config.py`, `fee_system.py`, `DATA_DICTIONARY.md`, and `RELATIONSHIPS_AND_RULES.md`.
- Transformations: derived IDs, term fees, invoice lines, eligibility, awards, payment allocations, refunds, anomaly labels, and validation reports are produced by the generator.
